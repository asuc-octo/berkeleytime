## Checklist
1. **Totals:** "8 Upper Division courses are required ... (3 Core courses + 5 Elective courses)". The three core rules plus the 5-course elective rule already enforce this, since each course counts once, so no total rule was added. The "36 required upper division units" sentence is about Rausser residency (see below), not a separate major total.
2. **Double counting:** default. The sheet says "ECON C125/ENVECON C101 cannot be counted as a core req and an elective". The 5-ENVECON rule is explicitly allowed to re-count core and elective courses, so it is `shared`.
3. **Electives:** the catalog's 29-course list was replaced with the department's pre-approved spreadsheet (~250 courses).
4. **Caps:** none that can be encoded. Residency: 15 of the 36 upper-division units must be taken in Rausser College (log only).
5. **Missing blocks:** the "at least 5 Upper Division ENVECON courses" requirement existed only as a placeholder. It is now a real rule.
6. **Either/or paths:** none. The core blocks are already "choose 1 of" rules.
7. **Placeholders:** "Upper Division" became the 5-ENVECON rule. "Course Requirements" (empty, no text) stays as a manual check.
8. **Contradictions:** the catalog's elective list is far narrower than the department sheet it links to. The Microeconomics rule lists ECON 100A twice (left as is; see open questions).
