# backend

Express + Apollo GraphQL API for berkeleytime.com. Full documentation:
[docs.berkeleytime.com/core/backend](https://docs.berkeleytime.com/core/backend/) and
the repository `AGENTS.md`.

```
src/
  main.ts                    entrypoint: imports ./instrumentation first (OpenTelemetry), then bootstrap
  instrumentation.ts         OTel SDK (traces, metrics, logs) when OTEL_EXPORTER_OTLP_ENDPOINT is set
  bootstrap/
    index.ts                 Express app, request logging, /healthz
    loaders/                 mongoose, redis, apollo, express (routes, CORS, helmet, passport)
    graphql/                 schema build, @auth directive, persisted-operation gateway (+ tests)
      generated/             persisted operation allowlist (generated by npm run generate:operations)
  modules/<domain>/          resolver.ts, controller.ts, formatter.ts, optional routes.ts and jobs/
  lib/                       logger (pino), metrics (OTel instruments)
  utils/                     cache helpers, mailer, S3 client, term/subject helpers
  types/                     request context type
codegen.ts                   GraphQL Code Generator config (graphql-modules preset)
scripts/
  prepare-typedefs.js        copies packages/gql-typedefs/*.ts into each module's generated-typedefs/
  generate-operation-allowlist.mjs   builds the persisted-operation allowlist from all gql`` documents
```

Configuration is read from `.env` by `packages/common/src/utils/config.ts`
(shared with the datapuller). Copy `.env.template` to `.env` at the repo root.

```sh
npm run dev -w apps/backend        # tsx watch (normally run inside docker compose)
npm run test -w apps/backend       # node:test via tsx, src/**/*.test.ts
npm run generate -w apps/backend   # regenerate module types after a schema change
```

There is no compile step: production runs `tsx src/main.ts` inside the image.
